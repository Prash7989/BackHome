# BackHome

Website for BackHome, helping NRIs coordinate property, family, paperwork, and everyday tasks in Hyderabad.

## Live website

https://backhome-hyderabad.prashanthreddy80088.chatgpt.site

## Files

- `dist/index.html` — page content and WhatsApp links
- `dist/styles.css` — styling and responsive layouts
- `dist/app.js` — mobile navigation
- `dist/brand.png` — BackHome branding
- `dist/hyderabad.jpg` — Hyderabad photograph

## Preview locally

Open `dist/index.html` in your browser, or run `python3 -m http.server 8000 --directory dist` from this repository and visit `http://localhost:8000`.

No package installation or build step is required.

## Make changes

Edit the files in `dist/`, then commit your changes. The WhatsApp links use `https://wa.me/917075537621` with service-specific message text.

## Publishing

The current live website is hosted separately through ChatGPT Sites. This repository is a copy of its source; automatic deployment from this GitHub repository is not configured. GitHub commits alone will not update the live site. Ask for the changes to be applied and published to the existing Site, or configure another hosting service to publish the `dist` directory.
